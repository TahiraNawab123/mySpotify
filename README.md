# 🎵 mySpotify

A lightweight Spotify-inspired music streaming and playlist manager built for learning and experimentation.

# Project Overview

mySpotify is a simple music streaming–style application that allows users to browse songs, play audio tracks, and manage playlists.
The goal of this project is to explore media handling, user interfaces, data management, and software architecture while building a real-world inspired application.

This project is designed for fun only.

# Key Features

- Play, pause, and skip songs

- Display track information (title, artist, duration)

- Playlist creation and management

- Search songs in the library

- Favorites / liked tracks

- Clean and modular project structure
